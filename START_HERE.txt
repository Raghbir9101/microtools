🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Port 3000 in use?
  $ pnpm dev -p 3001

Dependencies won't install?
  $ rm -rf node_modules
  $ pnpm install

Image not compressing?
  - Check browser console (F12)
  - Try JPG or PNG file
  - Clear browser cache

Build fails?
  $ npm run build
  $ npm start
